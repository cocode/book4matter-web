# Book4matter Web

Book4matter turns plain text and Markdown manuscripts into formatted books,
handling typography, chapter layout, and page numbering. It can produce print ready
pdf files, pdf files for distribution as files, html, and epub files. 

Just drag your chapter files onto this page, provide a title and author and you are ready to go.


This page is a web version of [Book4matter](http://book4matter.com)

Publishing runs in a Web Worker on the user's
device. Your files do not leave your computer.
