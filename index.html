Format Your Manuscript for Publication

Book4matter turns plain text and Markdown manuscripts into formatted books, handling typography, chapter layout, and page numbering. Add your chapters and create a book for print, screens, or an e-reader. Everything happens in your browser. None of your files are uploaded to a server.

How do chapters work?

Each plain text (.txt) file without headings becomes one chapter.

In Markdown, use # Section Title for a part of the book and ## Chapter Title for a chapter within it.

For a book without parts, set no-parts: true in book_metadata.yaml. Then # marks a chapter and ## marks a heading within it.

Which files can I add?

Add Markdown (.md) or plain text (.txt) chapters in as many batches as you like. You can also add images, fonts, book_metadata.yaml, and book_style.yaml.

If your chapters reference files in other folders, add the whole book folder so those links work. Without settings files, you can enter your book details below and use the default styling.
